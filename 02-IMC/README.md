# Calculadora de IMC en Java 📏⚖️

Programa que calcula el Índice de Masa Corporal (IMC) a partir del peso y la estatura, e indica en qué categoría se encuentra.

## 🎯 ¿Qué hace?

1. Pide el peso (kg) y la estatura (m) del usuario
2. Calcula el IMC con la fórmula: `imc = peso / (estatura * estatura)`
3. Indica la categoría: bajo peso, normal, sobrepeso u obesidad

## 📚 Lo que aprendí

- Operadores lógicos en Java: `&&` (equivalente al `and` de Python)
- Concatenación de texto con variables usando `+`
- Refuerzo de `if / else if / else` con la sintaxis de Java

## 🚀 Cómo ejecutarlo

```
java Main.java
```
