# Calculadora de Promedio de Notas (Java) 📊

Programa que permite ingresar varias notas y calcula el promedio, la nota más alta y la más baja.

## 🎯 ¿Qué hace?

1. Pregunta cuántas notas se van a ingresar
2. Pide cada nota una por una
3. Calcula el promedio, la nota más alta y la más baja

## 📚 Lo que aprendí

- Arrays (`double[]`) — tamaño fijo, a diferencia de las listas de Python
- Cómo llenar un array con un bucle `for`
- Cómo recorrer un array ya lleno en un segundo bucle, para sumar y comparar valores
- Por qué a veces se necesitan dos bucles separados (uno depende del otro ya terminado)
- El `for` completo de Java: `for (int i = 0; i < cantidad; i++)`

## 🚀 Cómo ejecutarlo

```
java Main.java
```
