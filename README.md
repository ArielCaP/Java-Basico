# Calculadora en Java 🔢

Mi primer proyecto en Java. Es una calculadora básica que permite hacer sumas, restas, multiplicaciones y divisiones entre dos números.

## 🎯 ¿Qué hace?

1. Le pide al usuario dos números
2. Le pregunta qué operación quiere realizar (+, -, *, /)
3. Muestra el resultado
4. Evita el error de dividir entre cero, avisando al usuario en vez de romper el programa

## 🛠️ Tecnologías usadas

- Java

## 📚 Lo que aprendí

- Estructura básica de un programa Java: `public class` y `public static void main`
- Comentarios en Java (`//` y `/* */`)
- `Scanner` para leer datos ingresados por el usuario
- Tipos de datos explícitos: `double` (decimales) y `String` (texto)
- `.equals()` para comparar textos (en Java no se usa `==` para eso)
- Condicionales `if / else if / else` con la sintaxis de llaves `{ }`
- Uso de `.gitignore` para excluir archivos generados automáticamente (`.class`, `tempCodeRunnerFile.java`)

## 🔄 Diferencias notadas con Python (mi otro lenguaje en aprendizaje)

| Python | Java |
|---|---|
| No necesita clases obligatorias | Todo va dentro de una clase (`public class Main`) |
| `input()` genérico | `Scanner` con métodos específicos (`nextDouble()`, `next()`) |
| No declaras tipos | Debes declarar el tipo de cada variable (`double`, `String`) |
| `==` sirve para comparar texto | Se necesita `.equals()` para comparar texto |
| Indentación define bloques | Llaves `{ }` definen bloques |
